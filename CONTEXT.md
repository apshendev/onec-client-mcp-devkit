# Глоссарий проекта

Термины client_mcp и сопутствующих подсистем. Определения описывают смысл, не реализацию.

## Провайдер

Общий модуль расширения, поставляющий MCP-серверу свои инструменты, ресурсы и промпты через процедуру
`Зарегистрировать`. Провайдер опознаётся по принадлежности подсистеме с суффиксом `_Мсп_Провайдеры`.

## Инструмент

Функция, вызываемая MCP-клиентом по имени с JSON-аргументами. Задаётся именем, описанием, схемой параметров
и обработчиком. У каждого инструмента один владелец-провайдер и переключатель включённости.

## Источник регистрации

Ссылка, передаваемая при регистрации в `Зарегистрировать` и определяющая происхождение инструмента,
ресурса или промпта: расширение-провайдер либо точечная регистрация из кода. По ней реестры связывают
элементы с провайдером и управляют их включённостью.

## Живая база

Информационная база, в которой 1С-клиент с запущенным MCP-сервером работает в момент вызова инструмента.
Все инструменты читают метаданные и данные той базы, где они исполняются.

## Деградация ответа (warnings)

Частичный успех: инструмент возвращает собранные данные и непустой список `warnings` с описанием того,
что прочитать не удалось. Отказ не выдаётся, если основной объём ответа собран.

## Подтверждение сохранения (двухфлаговое)

Правило фиксации изменений для инструментов, исполняющих код в транзакции: транзакция фиксируется
только при одновременном `allow_changes=true` и `confirm=true`. Любой другой набор флагов приводит
к откату либо к отказу до исполнения.
