- В ChildObjects Configuration.xml (Designer-XML) перечисляй объекты только именем без uuid-атрибута; uuid с атрибутом на элементе ChildObjects зацикливает XML-импорт платформы (бесконтрольный рост памяти до падения и в ibcmd, и в DESIGNER).
- В v8project.mcp-instruments.yaml держи builder: IBCMD; полный 1cv8 DESIGNER для локальной загрузки расширений не запускать (патологический рост памяти), .cfe выгружать только в CI.
- Перед каждым повтором сборки после таймаута/падения удаляй stale-лок v8-runner: build/.v8-runner.workspace.lock и .lock.json (после проверки, что pid из lock.json мёртв).
- Сборку/импорт контура mcp_instruments запускай только по прямой команде пользователя.
2026-09-05: Для генерации XML-исходников 1С (Configuration.xml и т.п.) использовать инструменты unica (cfe_init/cf_init с параметром cwd, outputPath игнорируется), а не писать файлы вручную.
- Любые команды по базам devkit (в т.ч. build/ib-live) запускать с явным таймаутом не более 2 минут; дольше - считать блокером, останавливаться и отчитываться, не запускать без таймаута. Фоновый запуск (Start-Process и т.п.) — тоже под таймаутом: сразу после запуска ждать `Wait-Process -Timeout 120` с принудительным Kill при превышении; «отпустить» процесс без контроля = запуск без таймаута.
2026-09-05: build/ib-live — авторизация «Администратор»/пустой пароль: ibcmd всегда с `--user=Администратор --password=`; тонкий клиент — только `/N Администратор` (ключа /User у 1cv8c нет); ibcmd резолвит относительные пути от своего каталога standalone-server — передавать абсолютные.
2026-09-06: Ответ пользователя в любой форме (устно, в чате, через инструмент) — это дизайн-решение: интерпретировать буквально и выполнять, не переспрашивать.
2026-09-06: Ветку фичи создавай от текущего HEAD пользователя, не от master.
2026-09-06: Не оформляй установленные факты как риски — риск только то, что может произойти или не произойти.
2026-09-06: CRLF внутри base64-литералов и base64-строк ломает Base64Значение/XMLЗначение в совместимости 8.3.16+ — в исходниках BSL собирай длинные base64 конкатенацией однострочных кусков и вырезай ВК+ПС перед XMLЗначение.
2026-09-06: ВнешниеОбработки.Подключить не компилирует модуль объекта — после подключения всегда верифицируй ВнешниеОбработки.Создать, чтобы синт-ошибка всплыла как compile_error, а не runtime.
2026-09-06: ОписаниеОшибки() в 8.3.20 не содержит координат {Модуль(N,M)} — для номера строки парси ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()).
2026-09-06: Вычислить не видит переменные, созданные Выполнить динамически; для чтения «Результата» после Выполнить используй статическую Перем с маркером (GUID-нуль), а не Вычислить("Результат").
2026-09-06: Методы потоков (ЗакрытьИПолучитьДвоичныеДанных и т.п.) не резолвятся из кода, исполненного Выполнить — используй БуферДвоичныхДанных; зато Выполнить-фрагменты видят локальные (неэкспортные) функции модуля-исполнителя — главный приём интроспекции.
2026-09-06: Строковые интервалы ("А".."я") для кириллицы в BSL не работают — проверки символов пиши через КодСимвола.
2026-09-06: `ibcmd extension list` на build/ib-live уходит в бесконечный интерактивный запрос пользователя — не использовать; состояние расширений ib-live проверяй живым запуском клиента.
2026-09-06: Модули одного расширения не видят имена модулей другого (компиляция падает «Переменная не определена»); для тестов чужого расширения встраивай мост-функции в само расширение (клиентский модуль без ВызовСервера), а движок YaxUnit — в tests-расширение, как в CI.
2026-09-06: STDOUT-пайп запущенного процесса переполняется и дедлокается, если не читать его во время работы — используй RedirectStandardOutput/Error в файлы, никогда не читай пайп после WaitForExit.
